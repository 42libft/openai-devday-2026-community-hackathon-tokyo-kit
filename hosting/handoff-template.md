# 公開先のhandoff票

- 公開先:
- owner / 公開担当:
- 代行担当と、その人が実際にできた操作:
- 使用する正式repoと採用commit:
- 確認用URL:
- project / Site識別子（公開可能な範囲）:
- 一般閲覧者で確認した日時・結果:
- 最小更新の手順:
- rollback / 前の版へ戻す手順:
- 環境変数名（値は書かない）:
- build / output設定:
- 制限 / 未解決:

handoff完了は、指定担当者がURLを開き、更新方法と担当範囲を理解できたことを確認してから記録する。権限を渡す必要がある場合は、対象者と範囲を確定して承認済みの手順で行う。APIキーやtokenをこの票やチャットに貼らない。
